# 给不活跃邮箱注册用户发送"微信小程序上线"公告邮件

## 收件人筛选（已确认口径）

Prisma 查询条件（`lastActiveAt` 为 Timestamptz，无时区歧义）：

```ts
prisma.user.findMany({
  where: {
    email: { not: { endsWith: "@placeholder.yuanlu.com" } }, // 真实邮箱（含手机注册后绑邮箱者）
    role: { not: "ADMIN" }, // 排除管理员账号
    OR: [
      { lastActiveAt: { lt: new Date("2026-10-04T09:00:00+08:00") } }, // 北京时间
      { lastActiveAt: null }, // 从未活跃（已确认包含）
    ],
  },
  select: { userid: true, email: true },
});
```

## 交付物：`scripts/send-weapp-launch-email.ts`

遵循项目 scripts 惯例（同 `upload-channel-covers.ts`：顶部手动解析 `.env` → 动态 `import @/lib/prisma` → `npx tsx` 运行）。注意 `.env` 的 `EMAIL_FROM` 是 `${SMTP_USER} <${EMAIL_FROM_ADDRESS}>` 字面量，脚本手动解析不展开变量，发件人需自行拼接为 `远路播客 <wxk-zd@qq.com>`。

**CLI 模式：**

- 无参数 = dry-run：只查名单，输出统计（总数、lastActiveAt=null 数、已绑 wxOpenId 数、手机+绑邮箱数、邮箱域名 top 分布）与前 20 条预览，不发送
- `--to <email>`：发单封预览到指定邮箱（给站长确认渲染效果用）
- `--send`：全量发送（自动跳过已成功发送的）
- `--limit N`：本次最多发 N 封（QQ SMTP 日配额约 100/天，量大分批用）
- `--interval <sec>`：发送间隔（默认 5s + 0~2s 随机抖动）

**防重发/断点续传：** 状态文件 `scripts/.weapp-launch-email-state.json` 记录已成功发送的 `{userid, email, sentAt}`，每封成功即写入；重跑自动跳过已发送的，中断可续传。若 `.gitignore` 未覆盖该文件则追加。

**发送实现：** nodemailer（host=SMTP_HOST、port 465 SSL、auth=EMAIL_FROM_ADDRESS/SMTP_PASS，与项目现有 4 处先例一致）；逐封单收件人发送 + 节流间隔（避免被 QQ 判定群发垃圾邮件）；单封失败记录并继续，结束输出成功/失败/跳过汇总。

**邮件内容**（复用 `app/(main)/app/page.tsx` 的 ANNOUNCEMENT 文案，全部内联 style 保邮件客户端兼容，不用 flex/grid）：

- 主题：`远路播客微信小程序正式上线`
- HTML（600px、品牌色远青 `#1F7A5C` + ink 暖纸色系，风格对齐 /app 落地页）：badge「产品公告 · 2026 年 10 月」→ 标题 + lead（"把远路装进微信…"）→ 两段正文 → 小程序码图片（线上地址 `https://www.wxkzd.com/static/images/miniprogram-code.png`）+ "在微信里找到我们"两步引导（扫一扫 / 微信搜索「远路播客」）→ 六项功能亮点 → CTA「查看公告详情」链接 `https://www.wxkzd.com/app` → 页脚 `© 2026 远路播客` + "您收到此邮件是因为您在远路播客注册了账号；如不想再收到产品通知，可直接回复本邮件告知"（项目无退订机制的替代处理）
- text 纯文本兜底：正文 + 链接 + 搜索小程序引导

## 执行流程

1. 写脚本，跑 tsc + eslint 校验
2. **dry-run**：输出名单规模与统计 → 若超约 90 封，提示分批方案（`--limit`，隔天续跑）
3. `--to wxk-zd@qq.com` 发预览邮件 → **停下来等你在 QQ 邮箱确认文案与渲染效果**
4. 确认后执行 `--send` 全量发送（或分批），汇报发送汇总

脚本默认不提交 git（如需入库可后续走 universal-git-flow）。
