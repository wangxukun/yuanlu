# 把精读页扫光高亮迁移到语音评测卡播放句

## 目标

点击「原声播放」「慢速播放」时,卡片顶部英文句子的单词呈现与 FullContentTranscript 一致的**随语速线性扫光**(背景光斑由前到后)+**已读词 accent 字体色**。AI朗读(TTS)不加扫光(避免误导)。仅迁移动画+配色,不动卡片容器样式。

## 核心技术对齐

精读页 hook 直读 `audioRef.currentTime`。评测卡有两种播放:

- **原声/慢速**(Web Audio API):时间 = `playStartOffset + (ctx.currentTime - playStartCtxTime) * playbackRate`。`subtitle.words` 是**绝对全集秒**,播放从 `rawStartTime`(绝对秒)起,所以词级时间戳比较**天然有效**,逻辑可直接复用。✓
- **TTS**(`new Audio`):合成音频,与词时间戳无关 → **不加扫光**。

## 设计:抽出一个可复用的 controller-based hook

把 `useWordHighlight` 的「DOM 写入 + 透明度/颜色插值」核心抽出,改成**不依赖 audioRef**,而是接收一个 `controller: { getTime: () => number; isPlaying: () => boolean }`。各调用方自行提供 controller。

新建文件 `components/transcript/useWordHighlight.ts`,导出:

- `useWordHighlight({ controller, containerRef, isHighlighted, words, start, end })`
- 颜色常量与插值逻辑(背景扫光 + 已读 accent 字体色),与精读页**完全一致**的实现。

### 1. 新建 `components/transcript/useWordHighlight.ts`

内容 = 从 `FullContentTranscript.tsx` 提取的 hook,入参 `audioRef/isActive/isPlaying` 改为:

```ts
controller: {
  getTime: () => number; // 当前播放秒(绝对)
  isPlaying: () => boolean; // 是否正在播放
}
isHighlighted: boolean; // 替代 isActive && isPlaying 的合并开关
words, start, end, containerRef;
```

颜色常量 `ACCENT_BG_LIGHT/DARK`、`READ_TEXT_LIGHT/DARK` 一并搬入并 export(供两处共享,避免魔法数字分叉)。

### 2. `FullContentTranscript.tsx` 改为复用新 hook

- 删除文件内的 hook 与颜色常量,改为 `import { useWordHighlight } from "@/components/transcript/useWordHighlight"`。
- 调用处包一层 controller:

```ts
useWordHighlight({
  controller: {
    getTime: () => audioRef?.currentTime ?? 0,
    isPlaying: () => !!audioRef && !audioRef.paused,
  },
  containerRef: textRef,
  isHighlighted: isActive && isPlaying,
  words: sub.words,
  start: sub.start,
  end: sub.end,
});
```

行为不变(回归安全)。

### 3. `useSpeechEvaluation.ts` 暴露 controller

在 hook 返回值新增:

```ts
highlightController: {
  getTime: () => number; // 原声/慢速:Web Audio 当前绝对秒;其它(停止/TTS):-1
  isPlaying: () => boolean; // 仅原声/慢速播放中为 true
}
```

- `getTime`:播放中复用 `tick` 里同款计算 `playStartOffset + (ctx.currentTime - playStartCtxTime) * playbackRate`;为避免每帧新建闭包,用一个 **module-level / ref 存的 getter**(`refGetTimeRef`),`startPlayback` 时把闭包塞进 ref,`stopAllAudio`/`onended` 时置空。getter 读 ref,返回 -1 表示无原声在播。
- `isPlaying`:`() => !!activeSourceRef.current`。
- TTS 播放时 `activeSourceRef.current` 为 null → controller 返回不播放 → hook 不点高亮。✓ 自然满足「TTS 不加扫光」。

### 4. `SpeechEvaluationCard.tsx` 接入

- 从 hook 解构 `highlightController`。
- 顶部英文句容器加 `ref`(textRef)。
- 词 span 加 `data-wi={idx}`(仅 `subtitle.words` 分支;`textEn.split` 分支无时间戳、播放也走原声——但无词级时间无法扫光,沿用 data-wi 但 hook 在 words 缺失时不启动,保持静态)。
- 调用:

```ts
useWordHighlight({
  controller: highlightController,
  containerRef: textRef,
  isHighlighted: true, // 卡片自身即当前句,播放就高亮
  words: subtitle.words,
  start: subtitle.words?.[0]?.start ?? subtitle.startSeconds,
  end: subtitle.words?.[words.length - 1]?.end ?? subtitle.endSeconds,
});
```

- 不改容器 className(用户要求仅动画+配色)。词的 hover/难词下划线等保留。

## 行为矩阵(评测卡)

| 触发            | 英文句单词                                                    |
| --------------- | ------------------------------------------------------------- |
| 原声/慢速播放中 | 背景扫光(随语速线性) + 已读 accent 字体色 + 未读/当前 primary |
| AI朗读(TTS)中   | 无扫光(保持卡片默认样式)                                      |
| 未播放          | 静态默认样式                                                  |

## 验证

- `npx tsc --noEmit` 两文件无新增错误。
- 精读页回归:扫光效果不变。
- 评测卡:点原声/慢速,扫光从句首扫到句尾,已读词变 accent 色;点 AI朗读无扫光;停止后回落默认样式。
