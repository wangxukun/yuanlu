# 复习卡片：替换占位翻译 + 补齐字幕数据以激活扫光动画

## 两个任务的共同根因

复习页面复用 `<SpeechEvaluationCard>`,"样式与动画"本就在组件里。但 `mockSubtitle`(page.tsx:118-124)只给了 `textEn/startSeconds/endSeconds`,**缺 `textCn`(→ 任务1 占位"弱项句子复习")和 `words`(→ 任务2 扫光动画永不触发,因为 useWordHighlight 在无 words 时直接 return)**。

→ 两个任务本质是**一个问题**:给复习卡片补齐真实的字幕数据(`textCn` + `words` + 精确 `endSeconds`)。补齐后:

- 任务1 自动解决(显示真实中文)
- 任务2 自动解决(原声/慢速播放扫光激活)

## 数据来源

`textCn` 与 `words` 都在**双语字幕 JSON**里,通过 `mergeSubtitles(episode)` 获取(与 practice-data 路由同一来源)。`errors` API 目前只返回 DB 记录(无字幕字段),需补齐。

## 匹配策略(每条 record → 对应字幕项)

record 有 `targetText`(英文)+ `targetStartTime`(秒)。剧集合并字幕逐项比对:

1. **文本相等优先**:`subtitle.textEn === record.targetText`
2. **时间兜底**:`|subtitle.start - targetStartTime| < 0.5`
   命中即取该项的 `textCn` / `words` / `end`(修正当前硬编码 `start+3` 的不精确结束时间)。

## 改动方案

### 1. `/api/speech/errors/route.ts`:为每条 record 附加字幕数据

- `include.episode.select` 补 `subtitleBilingualUrl/subtitleBilingualFileName/subtitleEnUrl/subtitleEnFileName/subtitleZhUrl/subtitleZhFileName`(mergeSubtitles 依赖这些 URL/FileName 字段,generateSignatureUrl 已有模式可复用)。
- 按剧集分组(当前 records 天然跨剧集),**每剧集只 `mergeSubtitles` 一次**(缓存),避免重复 fetch+decode。
- 为每条 record 用上述匹配策略找到字幕项,附加到返回结构:
  ```ts
  record.subtitleTextCn = matched?.textCn ?? "";
  record.subtitleWords = matched?.words; // 词级时间戳(可能 undefined)
  record.subtitleEnd = matched?.end; // 精确结束秒
  ```
- 匹配失败(字幕缺失)时优雅降级:`textCn=""`、`words=undefined`、`end=start+3`(保持原行为)。

### 2. `app/(main)/library/pronunciation/practice/page.tsx`:用真实数据填充 mockSubtitle

```ts
const mockSubtitle: Subtitle = {
  id: currentRecord.subtitleId || currentRecord.recognitionid,
  startSeconds: currentRecord.targetStartTime || 0,
  endSeconds:
    currentRecord.subtitleEnd ?? (currentRecord.targetStartTime || 0) + 3,
  textEn: currentRecord.targetText,
  textCn: currentRecord.subtitleTextCn || "", // ← 替换 "弱项句子复习"
  words: currentRecord.subtitleWords, // ← 激活扫光动画
};
```

- `textCn` 为空字符串时 `SpeechEvaluationCard` 的 `{subtitle.textCn && ...}` 自然不渲染翻译行(已是不渲染逻辑)。
- 无需改 page 的 TS 类型(`currentRecord` 是 `any`,字段自由扩展)。

### 3. 不改动 SpeechEvaluationCard

组件已有的 `textCn` 渲染、`useWordHighlight` 扫光在拿到 `words` 后自动生效,**零改动**。

## 行为矩阵

| 字幕数据情况       | 复习卡英文句 | 翻译行       | 原声/慢速播放 |
| ------------------ | ------------ | ------------ | ------------- |
| 有 textCn + words  | 正常         | 显示真实中文 | 扫光动画      |
| 有 textCn,无 words | 正常         | 显示真实中文 | 无扫光        |
| 无 textCn          | 正常         | 不渲染       | 取决于 words  |

## 验证

- `npx tsc --noEmit` 两个文件无新增错误(errors 路由的 prisma select / mergeSubtitles 调用)。
- 复习页:翻译行显示真实中文(非"弱项句子复习");点原声/慢速播放,英文单词随语速扫光。
