## 日常增量

流程详见 [入库技能](.agents/skills/corpus-ingest/SKILL.md) 与 [标注技能](.agents/skills/corpus-annotate/SKILL.md)：

1. build-corpus-index --only-new --dry 预检，再实跑；英文 embed-corpus 可立即补灌。
2. annotate-clips → annotate-scenes → upsert-annotations，核对模型、run 与输入是否匹配。
3. 身份落库后 embed-scenes；仅处理 NULL 向量，已有向量不会因标题更新自动重算。
4. 计数/词级时间戳/junk/向量水位与评测集验收；零切片集会再次视为欠账，字幕修正集须显式重建，--only-new 不会更新已有集。

脚本读取 DATABASE_URL，annotate 也读取数据库，并非离线零凭据工具。工作站产物与生产写入权限分开管理；先确认目标环境，生产迁移与回填不属于本轮文档巡检。

## 音频协议与稳定性

网关支持 clipid / sceneid；响应 url、duration、clipOffset。时间轴换算遵循 offset；当前默认对象名 `yuanlu/clips/{id}.aac`，有 contentHash 时 `{id}-{hash8}.aac`，编码 AAC/ADTS、64kbps、24kHz、mono。buildFfmpegArgs 仍保留 MP3 参数分支，不能据其默认值推断当前网关格式。

cutStart/cutEnd 合法时优先用预计算窗；否则 start−0.25s / end+0.35s，150ms 淡入淡出，45 秒硬闸。懒生成+OSS 缓存已实现；全量预切片、响度归一并未因此自动完成。

## 有效约束与待办

- 保持共享 Web/移动响应兼容，schema 优先 additive；sceneKey、clipid 与缓存引用稳定，不重建平行 Clip/Scene 表。
- 不为了命中率无评测放宽 minWords/minDuration/junk/场景切分参数；难度不直接交给 LLM，复用现有确定性口径。
- 质量门槛保留：worthiness P≥0.85；复标 κ≥0.75；检索同池 Recall@10 目标≥0.7；边界吞音/截尾<2%、串入下句<1%；响度极差≤3LU。目标值不代表目前已达标。
- 待办：clip_vocab 精确倒排消费、match 的检索后 RAG 文案组装与 generated_scene 运行时缓存、全量预切片/源级响度处理及 manifest 对账、自动增量调度、坏边界子集重对齐。schema 中已有表不等于对应服务已接入。
- 生产小程序已接原声工坊/微流，不再列作“尚待从 A 工程迁移”；其当前产品边界查 [COMPANION-DESIGN.md](../yuanlu-weapp/COMPANION-DESIGN.md)。

评测工具：[scripts/eval](scripts/eval)；历史评测数据保留于 .local/eval/，场景实验在 .local/scene-benchmark/。它们是带数据版本的历史证据，不代表当前线上水位。基础回归：`npm run test:corpus`；今日挑战另跑 `npm run test:daily`。
